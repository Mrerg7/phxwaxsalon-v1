# phxwax.salon

Informational static site for a Phoenix Brazilian wax salon concept.

**Domain available for acquisition** → [sales@desertrich.com](mailto:sales@desertrich.com)

## Stack

- **Astro 5** — pure static output (`output: 'static'`)
- **Tailwind CSS 3** + Typography
- **TypeScript** (strict)
- **@astrojs/sitemap**
- **Cloudflare Workers Static Assets** (no adapter)

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npx wrangler deploy
```

## Key Features

- Fully static, edge-optimized
- Complete Open Graph + structured data (WebSite, WebPage, FAQPage)
- Mobile-first responsive design
- Sophisticated domain-acquisition CTA
- robots.txt + auto-generated sitemap
